# حَصاد التعليمية — الحصص الأسبوعية أونلاين

موقع للمعلم يضيف فيه شعبًا وحصصًا أسبوعية، والطالب يدخل برمز يشاهده داخل الصفحة.

المستودع: https://github.com/k100ed10-alt/hasad-educational

## التشغيل

افتح الملفات في متصفح، أو:

```bash
python3 -m http.server 8080
```

## الصفحات

- `index.html` الرئيسية
- `teacher.html` لوحة المعلم
- `join.html` إدخال الطالب
- `classroom.html` مشاهدة الحصة
